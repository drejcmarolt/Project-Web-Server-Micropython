# Project-Web-Server-Micropython
Ta projekt je o spletne strežniku v programske jeziku Micropythonu, ki prikazuje stanje LED in IR diodah ter prikazovanje grafa o temperaturah. Prikazuje tudi primera z LED diodami, kot sta semafor in kviz.
Ta projekt deluje na plošči Raspberry Pi Pico W. Ta projekt, ki ima spletni strežnik, naj bi bil povezan z Hotspot-om Raspberry Pi.
